# myholypoly

myholypoly는 e-POLY의 숙제 일정을 가져와 보기 좋은 체크리스트로 정리하고, 월간 일정·진행 상태·메모를 한곳에서 관리하는 Windows용 데스크톱 앱입니다.

## 주요 기능

### e-POLY 일정 가져오기

- 앱에서 e-POLY를 연동 모드로 실행
- 로그인된 e-POLY 캘린더에서 날짜별 숙제 가져오기
- e-POLY가 설치되어 있지 않을 때 PC 설치 가이드 제공
- e-POLY가 종료되거나 연결이 끊기면 연결 상태 갱신
- 숙제가 없는 날짜도 오류 없이 안내

### AI 일정 자동 구성

Google Gemini API 키를 등록하면 일정을 가져오는 즉시 전체 과목을 한 번에 분석하여 할 일을 정리합니다.

- 과목명과 마감일 유지
- 교재명, 페이지, 날짜, 숫자 등 원문의 핵심 정보 보존
- 불필요한 안내 문구와 과도한 공백·줄바꿈 정리
- 잘못 분리된 문장 병합 및 여러 행동이 섞인 문장 분리
- 상위 활동과 세부 활동의 관계를 유지한 체크리스트 구성
- AI 처리에 실패하면 원본 일정으로 안전하게 전환

AI가 정리한 일정에는 `AI 정리` 표시가 붙습니다. 과목별 `원본 보기` 또는 `전체 원본 비교`를 사용해 가져온 원본과 정리된 결과를 비교할 수 있으며, 원하는 과목만 원본으로 복원할 수도 있습니다.

#### 사용자 추가 규칙

지점이나 담당 선생님마다 숙제 작성 방식이 다른 경우, **AI 설정 → 내 추가 규칙**에서 정리 기준을 직접 작성할 수 있습니다.

예시:

```text
별표(*)로 시작하는 문장은 새로운 상위 항목으로 처리해 주세요.
e-Poly 아래에는 Reading Challenge, Listening Practice, Read Aloud를 배치해 주세요.
Due Date와 Due on 문구는 마감일 판단에 사용해 주세요.
```

기본 안전 규칙은 항상 적용되며, 사용자 규칙은 이 PC에 저장되어 다음 일정부터 자동으로 사용됩니다.

### 일정 편집과 등록

- 과목을 최대 5개까지 추가
- 과목별 할 일 추가·수정·삭제
- 선택한 과목 삭제 및 최소 한 과목 유지
- 가져온 원본과 AI 결과 비교
- 등록한 일정의 할 일 내용을 진행 현황에서 다시 수정

### 전체 일정

- 월 단위 일정과 진행률 확인
- 이전 달·다음 달 이동 및 월 선택
- 현재 날짜를 기준으로 일정 영역 자동 위치 조정
- `마감 임박`, `오늘`, `이번 주`, `전체` 범위 필터
- 완료 항목 숨기기
- 필터와 완료 항목 숨기기 설정 유지

### 진행 현황

- 과목별 할 일 체크리스트
- 완료 개수와 남은 할 일 확인
- 모든 할 일이 끝난 과목은 `완료`로 표시
- 일정 수정·삭제 메뉴
- `Esc` 키로 열린 일정 메뉴 닫기
- 전체 일정과 동일한 필터 및 완료 항목 숨기기 설정 사용

### 메모장

- 메모장 제목 오른쪽의 `+` 버튼으로 새 메모 생성
- 메모 제목과 내용 편집
- 메모 작성·수정 시각 표시
- 필요 없는 메모 삭제

## 처음 사용하는 방법

1. 왼쪽 메뉴에서 **일정 등록**을 엽니다.
2. **e-POLY 실행**을 눌러 e-POLY를 연동 모드로 실행합니다.
3. e-POLY에 로그인한 후 **캘린더 열기**를 누릅니다.
4. 과제일을 선택하고 **일정 불러오기**를 누릅니다.
5. 가져온 과목과 할 일을 확인하고 필요한 부분을 편집합니다.
6. **일정 등록**을 눌러 저장합니다.
7. **전체 일정** 또는 **진행 현황**에서 숙제를 관리합니다.

e-POLY가 설치되어 있지 않다면 앱에 표시되는 [PC 설치 가이드](https://www.youtube.com/watch?v=g7CY3u4QoWU)를 따라 설치한 후 다시 시도하세요.

## Gemini AI 설정

AI 자동 구성은 선택 기능입니다. API 키가 없어도 e-POLY 일정 가져오기와 나머지 기능을 사용할 수 있습니다.

1. 일정 등록 화면의 `AI 자동 정리` 옆 **설정**을 누릅니다.
2. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 API 키를 발급받습니다.
3. 발급받은 키를 입력하고 **설정 저장**을 누릅니다.
4. 필요한 경우 **내 추가 규칙**을 작성해 함께 저장합니다.

API 키는 Windows 암호화 저장소를 이용해 이 PC에만 보관됩니다. 추가 규칙은 일반 텍스트로 로컬에 저장됩니다. AI가 연결된 상태에서 일정을 가져오면 숙제 내용과 추가 규칙이 일정 정리를 위해 Google Gemini API로 전송됩니다.

## 설치 방법

### 1. 파일 다운로드

[GitHub Releases](https://github.com/magune-lab/myholypoly/releases)에서 최신 버전을 열고 다음 파일을 다운로드합니다.

- `magune-lab.cer`: Windows가 앱 배포자를 확인하기 위한 공개 인증서
- `myholypoly-windows-x64-버전.appx`: 앱 설치 파일

### 2. 인증서 설치

> [!IMPORTANT]
> APPX를 실행하기 전에 인증서를 먼저 설치해야 합니다. 저장 위치는 반드시 **로컬 컴퓨터 → 신뢰할 수 있는 사용자(Trusted People)** 로 지정하세요.

1. `magune-lab.cer`를 두 번 클릭합니다.
2. **인증서 설치**를 누릅니다.
3. 저장 위치에서 **로컬 컴퓨터**를 선택합니다.
4. **모든 인증서를 다음 저장소에 저장**을 선택합니다.
5. **찾아보기 → 신뢰할 수 있는 사용자**를 선택합니다.
6. **다음 → 마침**을 눌러 설치합니다.

### 3. 앱 설치

`myholypoly-windows-x64-버전.appx`를 두 번 클릭한 후 **설치**를 누릅니다.

인증서는 PC마다 처음 한 번만 설치하면 됩니다. 이후에는 새 APPX를 기존 앱 위에 설치해 업데이트할 수 있습니다.

## 데이터 저장과 업데이트

사용자 데이터는 `%APPDATA%\myholypoly`에 저장됩니다.

- 등록한 일정: `plan.json`
- Gemini API 키: Windows 암호화 파일
- AI 사용자 추가 규칙: `ai-organizing-rules.txt`
- 메모 및 화면 필터 설정: Electron 앱 로컬 저장소

새 버전을 기존 앱 위에 설치해도 일정, 메모, AI 설정은 유지됩니다. 앱을 제거하면서 데이터를 삭제하거나 위 폴더를 직접 삭제하면 저장된 정보가 사라질 수 있습니다.

## 개발 환경에서 실행

```powershell
pnpm install
pnpm start
```

Windows 패키지 생성:

```powershell
pnpm run package:win
pnpm run package:msix
```
