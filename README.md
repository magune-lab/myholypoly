# myholypoly

myholypoly는 e-POLY의 숙제 일정을 가져와 과목별로 정리하고, 진행 상태와 메모를 관리하는 Windows용 숙제 플래너입니다.

## 주요 기능

- e-POLY에 표시된 숙제 일정 가져오기
- 가져온 과목과 숙제 내용을 등록 전에 편집
- 전체 일정과 월간 일정 확인
- 숙제별 완료 상태 관리
- 간단 메모 작성
- 앱을 업데이트해도 기존 일정과 메모 유지

## 설치 방법

### 1. 파일 다운로드

[Releases](https://github.com/magune-lab/myholypoly/releases)에서 최신 버전을 열고 다음 두 파일을 다운로드합니다.

- `magune-lab.cer`: Windows가 myholypoly의 배포자를 확인하기 위한 공개 인증서
- `myholypoly-windows-x64-버전.appx`: 앱 설치 파일

### 2. 인증서 설치

> [!IMPORTANT]
> APPX를 실행하기 전에 인증서를 먼저 설치해야 합니다. 저장 위치는 반드시 **로컬 컴퓨터 → 신뢰할 수 있는 사용자(Trusted People)** 로 지정하세요. 다른 위치에 설치하면 앱을 설치할 수 없습니다.

1. 다운로드한 `magune-lab.cer`를 두 번 클릭합니다.
2. **인증서 설치**를 누릅니다.
3. 저장 위치에서 **로컬 컴퓨터**를 선택하고 **다음**을 누릅니다.
4. 관리자 권한 확인 창이 나오면 허용합니다.
5. **모든 인증서를 다음 저장소에 저장**을 선택합니다.
6. **찾아보기**를 누르고 **신뢰할 수 있는 사용자**를 선택합니다.
7. **다음 → 마침**을 눌러 설치합니다.

### 3. 앱 설치

`myholypoly-windows-x64-버전.appx`를 두 번 클릭한 후 **설치**를 누릅니다.

인증서는 PC마다 처음 한 번만 설치하면 됩니다. 이후 업데이트는 새 APPX를 받아 기존 앱 위에 설치하면 됩니다.

## 업데이트와 데이터

새 버전의 APPX를 기존 앱 위에 설치하면 일정과 메모가 유지됩니다. 사용자 데이터는 `%APPDATA%\myholypoly`에 저장됩니다. 앱을 제거하면서 데이터 삭제를 선택하거나 해당 폴더를 직접 삭제하지 않는 한 그대로 남습니다.

## 처음 사용하는 방법

1. myholypoly에서 **일정 등록** 메뉴를 엽니다.
2. **e-POLY 실행**을 눌러 e-POLY를 연결합니다.
3. 캘린더에서 과제일을 선택하고 **일정 불러오기**를 누릅니다.
4. 가져온 과목과 숙제 내용을 확인하고 필요한 부분을 편집합니다.
5. **일정 등록**을 눌러 저장합니다.
6. **진행 현황** 또는 **월간 일정**에서 등록한 숙제를 관리합니다.

해당 날짜에 숙제가 없다면 과목 편집 영역은 비어 있으며, 상단 안내 메시지에 결과가 표시됩니다.
